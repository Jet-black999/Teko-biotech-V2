# Documentação do projeto

Para o desenvolvimento deste fork, comece pelo **[Plano de implementação V2](../PLANO-IMPLEMENTACAO-V2.md)** e pela [análise da migração](ANALISE-MIGRACAO-V2.md). A V2 prevê reformular as telas e integrar funcionalidades selecionadas. As referências abaixo documentam a base herdada; em decisões de evolução do fork, prevalece o plano V2.

A [entrega 0 — preparação da V2](ENTREGA-0-PREPARACAO-V2.md) registra o backup verificado, a branch de integração, o mapa de transferência, os testes iniciais e os bloqueios de ambiente.

A [entrega 1 — prévias das novas telas](ENTREGA-1-PREVIAS-V2.md) apresenta duas direções navegáveis em [`prototipo-v2/`](../prototipo-v2/README.md), com dados fictícios e sem instalação de dependências. A revisão visual e a escolha de direção estão pendentes; a [decisão de tecnologia](decisoes/001-previa-interface-v2.md) distingue o protótipo da futura integração.
